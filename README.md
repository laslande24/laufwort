# Laufwort

Practise German while you run. Lessons are spoken aloud, you answer out loud, and the session adapts to your effort.

Status: the interface is done (welcome, home, lesson player, effort flow, progress). Supabase auth and heart rate come next.

Expo SDK 57, Expo Router, Reanimated 4, TypeScript. On the web the app shows in a phone-width column.

```bash
npm install
npx expo start
```
